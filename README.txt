دفتر تنخواه من — بسته انتشار برای GitHub Pages

محتویات:
- index.html: برنامه
- manifest.webmanifest: مشخصات نصب روی صفحه اصلی آیفون
- sw.js: پشتیبانی آفلاین و کش برنامه
- icons/: آیکون برنامه

انتشار:
1) در GitHub یک مخزن جدید بسازید.
2) نام مخزن را مثلا daftar-tankhah بگذارید.
3) فایل‌های داخل این پوشه (نه خود پوشه) را در ریشه مخزن آپلود کنید.
4) Settings > Pages > Deploy from a branch را انتخاب کنید.
5) Branch: main و Folder: /(root) را انتخاب و Save کنید.
6) پس از انتشار، آدرس GitHub Pages را با Safari آیفون باز کنید.
7) Share > Add to Home Screen > Add.

توجه:
اطلاعات تراکنش‌ها و مانده اولیه در localStorage مرورگر همان دستگاه ذخیره می‌شود و به GitHub ارسال نمی‌شود.
پاک‌کردن Website Data یا داده‌های Safari ممکن است اطلاعات را حذف کند؛ مرتب خروجی Excel بگیرید.
این برنامه ورود کاربری/همگام‌سازی ابری ندارد.
